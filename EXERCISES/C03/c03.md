C 程序的五个基本组成部分
1. 预处理指令
#include <stdio.h>
作用：告诉预处理器，把标准输入输出头文件 stdio.h 中相关的声明引入当前程序。
2. 注释
/* 这是一个简单的 C 程序 */
注释是写给程序员看的，编译时不会作为普通程序代码执行。
3. 主函数
int main(void)
{
    // 程序主体
    return 0;
}
这是程序的入口。
- int：表示函数返回一个整数。
- main：主函数名称。
- void：表示不接受参数。
- {}：标记函数体的开始和结束。
4. 变量声明
int age = 18;
这行代码完成了三件事：
- int：指定变量类型为整数类型。
- age：变量名称。
- 18：初始化值。
变量是程序存储和操作数据的基本单位之一。
5. 函数调用与返回
printf("My age is %d.\n", age);
调用 printf() 函数输出内容。
其中：
- %d 是格式说明符，表示这里要输出一个整数。
- age 是提供给 %d 的变量。
- \n 表示换行。
最后
return 0;
表示主函数执行结束，并向操作系统返回状态码 0，通常表示程序正常结束。


声明与定义
int age;
第一行：声明一个 int 类型的变量 age。
int age = 18;
第二行：声明并定义变量 age，同时为它提供初始值.
严格来说，**声明（Declaration）**是告诉编译器某个标识符的类型和相关信息；**定义（Definition）**则是在需要时创建实体，例如为变量分配存储空间。
代码	          是否是声明	是否是定义	     是否初始化
int a;	           ✅	        ✅	           ❌
extern int b;	   ✅	        ❌（通常情况下）	❌
int c = 10;        ✅	        ✅	           ✅

1. int a;
这是变量的声明，同时也是定义。
因为它告诉编译器：
- 变量名称是 a。
- 类型是 int。
- 需要为变量分配存储空间。
2. extern int b;
这是一个外部变量声明。
extern 告诉编译器：
这个变量在其他地方定义，我这里只是引用它。
它通常不会在这里创建变量的存储实体。
3. int c = 10;
这是变量的声明、定义和初始化。
- int：类型。
- c：变量名称。
- 10：初始值。
它为变量定义存储空间，并将初始值设为 10。
声明（Declaration）
│
├── 仅声明（不定义）
│   └── extern int b;
│
└── 定义（Definition）
    ├── int a;
    └── int c = 10;

extern int y;       // 仅声明
extern int w = 30;  // 声明 + 定义 + 初始化

作用域（Scope）
变量位置	              作用域
函数外部定义的变量	     文件作用域
函数内部定义的变量	      块作用域
这是一段代码：
#include <stdio.h>

int number = 100;       // 文件作用域

int main(void)          // 第一层代码块
{
    int age = 18;       // 第一层代码块作用域

    {                   // 第二层代码块
        int score = 90; // 第二层代码块作用域
        printf("score = %d\n", score);
    }

    printf("number = %d\n", number);
    printf("age = %d\n", age);

    return 0;
}
可以把它理解成三个区域：
整个源文件
│
│  number = 100
│  ↓
│  可以在后面的函数中访问
│
└── main() 函数
    │
    │  age = 18
    │  ↓
    │  整个 main 函数内部都可以访问
    │
    └── 内部代码块
        │
        │  score = 90
        │  ↓
        │  只能在这个内部代码块中访问
        │
        └── 代码块结束，score 的作用域结束
         

内层可以访问外层，外层不能访问内层


变量的存储期
C 语言有四种存储期：
1. 自动存储期（Automatic Storage Duration）
2. 静态存储期（Static Storage Duration）
3. 线程存储期（Thread Storage Duration）
4. 分配存储期（Allocated Storage Duration）


1. 自动存储期
void test(void)
{
    int number = 10;
}

特点：
- 进入相关代码块时，变量的生命周期开始。
- 离开代码块时，生命周期结束。
- 再次进入代码块时，会重新创建一个新的自动存储期实例。

2. 静态存储期
void test(void)
{
    static int number = 10;

    number++;
    printf("%d\n", number);
}
这里的 static 改变了变量的存储期。
特点：
- 程序运行期间一直存在。
- 只初始化一次。
- 多次调用函数时，保留上一次修改的值。
